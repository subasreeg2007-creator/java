# KEC Student Academic & Continuous Evaluation System

## Project Description
A Java JDBC console application for managing student academic details and continuous evaluation records for Kongu Engineering College (R2024).

## Technologies Used
- Java
- JDBC
- MySQL
- Eclipse IDE

## Features
- Student management
- Course management
- Student enrollment
- Assessment marks entry
- View student marks
- Attendance management
- Attendance percentage calculation
- Internal marks calculation
- Final result calculation

## Requirements
- JDK 21
- MySQL Server 8.0
- MySQL Connector/J
- Eclipse IDE

## How to Run
1. Create the `kec_academic` database in MySQL.
2. Create the required tables and insert the necessary data.
3. Configure your own MySQL username and password in `DBConnection.java`.
4. Add MySQL Connector/J to the project's build path.
5. Run `MainMenu.java` in Eclipse.

## Note
This project was developed as an academic assignment. Verify the institution's official assessment rules before using the result calculation for real academic decisions.
